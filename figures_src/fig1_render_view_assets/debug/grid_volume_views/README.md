# Fig. 1 Front3D Grid Visualization Asset

Status: **superseded for the main Fig. 1 render panel**.

Use `../../final/` for the NeRF-MAE-style rendered RGB
view and bbox overlay. The assets in this directory visualize the extracted
`rgbsigma` grid and are kept only as auxiliary structure/alpha/debug material.

Selected scene:
- `3dfront_0131_00`

Source:
- `dataset/finetune/front3d_rpn_data/features/3dfront_0131_00.npz`
- This is a released Front3D NeRF-RPN/NeRF-MAE `rgbsigma` grid, not a schematic.

Why this scene was selected:
- The cropped view shows an indoor subregion rather than the entire room, closer
  to the way NeRF-MAE uses rendered scene snippets in its figures.
- The alpha view exposes wall/floor/furniture structure on the same crop.
- The RGB view contains a readable appearance signal on the same geometry.
- It was selected from a wider candidate scan because it is less cluttered than
  the full-room `3dfront_0062_00` and `3dfront_0135_00` candidates.

Rendered assets:
- `3dfront_0131_00_alpha.png`: cropped alpha/structure view.
- `3dfront_0131_00_rgb.png`: cropped RGB/appearance view.
- `fig1_front3d_0131_alpha_rgb_pair_clean.png`: clean side-by-side preview.
- `fig1_front3d_0131_alpha_rgb_pair.png`: labeled side-by-side preview.
- `3dfront_0131_00_view_contact_sheet.png`: three fixed view candidates.
- `render_view_vs_grid_view_debug.png`: debug comparison against the render-style
  panel included in the NeRF-MAE demo assets.

View policy:
- This directory contains an **external partial-volume grid view**: a cropped
  view from outside the released `rgbsigma` grid. It is no longer intended as
  the main Fig. 1 rendered RGB panel.
- A second **test-render-aligned view** would be useful for side-by-side
  comparison with GT/test RGB renders. It is not generated here because the
  current workspace does not contain the required rendered RGB image,
  `transforms.json`, or trained Instant-NGP checkpoint for this Front3D scene.
  If those artifacts become available, generate that view as a separate asset
  rather than replacing this external view.
- A real rendered RGB view is now available from the NeRF-RPN `front3d_nerf_data`
  release, so the main Fig. 1 panel should use `../../final/`.
  The released-grid visualization is visibly noisier than the NeRF-MAE
  render-style panel and should not be treated as a photorealistic render.

This supersedes the earlier scatter/point-splat render and the full-room
transparent render. The current assets are generated by orthographic ray
marching through the released `rgbsigma` grid, then editorially cropped and
trimmed for a first-page conceptual figure.

Generation command:

```bash
python figures_src/render_front3d_fig1_volume.py \
  --scene 3dfront_0131_00 \
  --out-dir figures_src/fig1_render_view_assets/debug/grid_volume_views \
  --width 1200 --height 780 --samples 192 --tile-rows 30 \
  --dpi 320 --alpha-threshold 0.07 --opacity-scale 0.17 \
  --azimuth -34 --elevation 60 \
  --saturation 1.9 --rgb-contrast 1.08 \
  --image-crop 0.04,0.02,0.86,0.82 \
  --depth-min 0.02 --depth-max 0.82 \
  --trim-threshold 0.985 --trim-margin 0.05 \
  --smooth-sigma 0.4 --rgb-mode surface \
  --render-view-candidates
```

Rendering details:
- Density is converted to alpha using the same Front3D conversion used by
  `nerf_rpn/datasets.py`:
  `alpha = clip(1 - exp(-exp(density) / 100), 0, 1)`.
- RGB values are exposure-normalized from occupied voxels and clipped to
  `[0, 1]` for visualization.
- RGB output uses a surface-color view: each ray takes the representative
  high-opacity sample and blends it over a white background. This is less noisy
  than showing the whole-room transparent color integral.
- The RGB view applies luminance-preserving saturation enhancement for figure
  readability. This does not create semantic colors; it only amplifies chroma
  already present in the released radiance grid.
- The alpha/structure output uses the same camera and accumulated opacity, with
  grayscale depth shading to expose room-scale structure.
- The crop, depth slab, auto-trim, and light smoothing are figure-display
  operations. The underlying source remains the released Front3D `rgbsigma`
  grid; this is not an Instant-NGP photorealistic render.
- The final pair is intended as a data-derived visual asset for the Fig. 1
  conceptual comparison; quantitative results should remain in Fig. 2 / Table 1.
