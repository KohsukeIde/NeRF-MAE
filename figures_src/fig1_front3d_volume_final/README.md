# Fig. 1 Front3D Volume Render Asset

Selected scene:
- `3dfront_0062_00`

Source:
- `dataset/finetune/front3d_rpn_data/features/3dfront_0062_00.npz`
- This is a released Front3D NeRF-RPN/NeRF-MAE `rgbsigma` grid, not a schematic.

Why this scene was selected:
- The alpha-only render exposes room-scale structure and furniture layout.
- The RGB render shows visible appearance/color signal on the same geometry.
- The scene has enough objects to make the structure/appearance contrast
  visually legible without being too cluttered for a first-page conceptual
  figure.
- It is more legible than the earlier `3dfront_0135_00` candidate, whose
  occupied RGB values are mostly low-chroma beige/gray and therefore looked
  nearly grayscale after white-background volume compositing.

Rendered assets:
- `3dfront_0062_00_alpha.png`: opacity-composited alpha/structure view.
- `3dfront_0062_00_rgb.png`: opacity-composited RGB/appearance view.
- `fig1_front3d_0062_alpha_rgb_pair_clean.png`: clean side-by-side preview.
- `fig1_front3d_0062_alpha_rgb_pair.png`: labeled side-by-side preview.
- `3dfront_0062_00_view_contact_sheet.png`: three fixed view candidates.

This supersedes the earlier scatter/point-splat render. The current assets are
generated by orthographic ray marching through the released `rgbsigma` grid and
front-to-back alpha compositing.

Generation command:

```bash
python figures_src/render_front3d_fig1_volume.py \
  --scene 3dfront_0062_00 \
  --out-dir figures_src/fig1_front3d_volume_final \
  --width 1120 --height 760 --samples 224 --tile-rows 28 \
  --dpi 320 --alpha-threshold 0.05 --opacity-scale 0.11 \
  --azimuth -42 --elevation 57 --saturation 2.4 \
  --render-view-candidates
```

Rendering details:
- Density is converted to alpha using the same Front3D conversion used by
  `nerf_rpn/datasets.py`:
  `alpha = clip(1 - exp(-exp(density) / 100), 0, 1)`.
- RGB values are exposure-normalized from occupied voxels and clipped to
  `[0, 1]` for visualization.
- RGB output is composited as `C = sum_i T_i * alpha_i * rgb_i` over a white
  background.
- The RGB view applies luminance-preserving saturation enhancement for figure
  readability. This does not create semantic colors; it only amplifies chroma
  already present in the released radiance grid.
- The alpha/structure output uses the same camera and accumulated opacity, with
  grayscale depth shading to expose room-scale structure.
- The final pair is intended as a data-derived visual asset for the Fig. 1
  conceptual comparison; quantitative results should remain in Fig. 2 / Table 1.
